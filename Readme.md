# Coupon Service 

---

## 프로젝트 소개
nhn아카데미 프로젝트에서 쿠폰을 담당하는 서버입니다.

---

## 무엇을 해결하는지

쿠폰을 다형성있게 만들려고 노력함.

## 주요 기능

### 쿠폰정책생성
- 쿠폰관련 기한과 할인 금액 등 정책을 정함.

### 쿠폰생성
- 쿠폰 수량이나 발행일, 쿠폰종류를 정함.

### 쿠폰발행 및 사용
- 생성된 쿠폰을 사용자가 받아서 사용할 수 있음.


### 도메인으로 풀려고 함.
- 쿠폰정책이나 쿠폰등 유효성 검사가 비즈니스로직이 은근히 까다로운 편이다.
  - 비율 할인은 100프로 이상이 넘으면 안됨.
  - 금액할인이 마이너스가 나오면 안된다.
  - 카테고리 쿠폰, 도서쿠폰, 도서 카테고리 상관없는 금액할인 쿠폰, 비율쿠폰
이것을 도메인으로 풀려고 했습니다.

## 생각들

### 조금더 다양한 쿠폰을 만들 수 있었는데 못했다.
지금 설계로는 필요한 쿠폰이 있을 때마다, 엔티티 필드가 늘어나는 구조이다.
설계를 조금 바꿔서 필요한 아이디를 늘리는 대신 타입명과 아이디를 받고, 이것을 다형성으로 푼다면, 더 좋은 코드가 되지 않을까 하는 아쉬움이 있다.
